# Personal Skills

个人 Claude Code Skills 仓库，用于存储和管理自定义技能配置。

## 技能列表

| 技能名称 | 命令 | 说明 |
|----------|------|------|
| Git Commit 生成器 | `/git-commit` | 自动分析代码改动并生成 Gitmoji commit message；支持一次确认后完成本地提交，推送仍需单独确认 |
| Repo 架构图生成器 | `/repo-architecture-flow` | 分析仓库结构并生成 Mermaid 架构图，支持导出 SVG/PNG/PDF |

---

## 备份说明

本仓库作为个人 Skills 的备份存储。
