# HTTP 接口条目模板（三档按需选用）

在设计文档（`lld.md` 或轻量模式的 `design.md`）中按“方法 + 路径”或明确接口动作分配独立编号与锚点，标题只保留状态、编号和业务名称，方法与路径写在正文首行或接口信息中。

按接口复杂度从下面**三档中任选一档**，不搞一刀切：

1. **一、简单 CRUD / 常规内部接口（默认）**：紧凑接口卡，直接看清 `Method + URL`、入参、出参和关键规则；同模块共享同一个 VO 时只在公共约定或首个接口写一次字段表，其余接口直接引用或给示例。
2. **二、存量接口增量修改**：只列 `Method + URL`、本次新增/修改/废弃的字段及差异示例，**不重抄未改动的存量字段**，避免冗长或臆测已有字段。
3. **三、复杂协议 / 对外回调 / 高并发状态机接口**：展开完整协议契约（详细 Header、完整 HTTP 请求/响应、逐状态错误表、幂等与并发边界）。

> 若仓库已存在 `AGENTS.md` 固化的响应包装（如统一 `WebResponse`）、鉴权头或命名风格，或使用 YAPI/OpenAPI 等接口平台维护全量 Schema，设计正文仅一句话引用公共约定及平台接口 ID，聚焦关键约束与差异即可。

## 一、简单 CRUD / 常规接口（紧凑卡，默认）

<a id="lld-3"></a>

### [x] 3. 新增资源

- 回链：[hld #1](hld.md#hld-1)；公共约定：[lld #1](#lld-1)
- 接口：`POST /api/resources`（`application/json`，需认证 Header）
- 结论：创建资源并返回详情；依据：已确认需求与仓库接口约定。

**入参**

| 位置 | 字段 | 类型 | 必填 / 可为 null | 说明 |
|---|---|---|---|---|
| Body | `name` | string | 是 / 否 | 去首尾空白后长度 1–100 |
| Body | `description` | string | 否 / 是 | 最长 500；缺失或 null 存为 null |

**出参示例**（`201 Created`，沿用公共响应包装时按项目实际外层展示）

```json
{
  "id": "res_001",
  "name": "示例资源",
  "description": null
}
```

**规则与异常**：校验失败返回参数错误（如 `400`）；列表接口简述筛选/排序/分页，删除接口说明软硬删与幂等语义，无需铺设全套空表。

## 二、存量接口增量修改（仅写差异）

<a id="lld-4"></a>

### [x] 4. 查询列表（新增筛选与返回字段）

- 回链：[hld #2](hld.md#hld-2)
- 接口：`POST /api/resources/page`（修改既有接口）
- 结论：仅新增以下筛选条件与返回字段，其余既有字段、分页包装与错误处理保持不变。

**变更字段**

| 方向 | 字段 | 类型 | 必填 / 可为 null | 说明 |
|---|---|---|---|---|
| 入参 Body | `status` | string | 否 / 是 | 新增可选筛选；缺失、null 或空白不筛选 |
| 出参 `content[]` | `owner_name` | string | 必有 / 是 | 新增展示字段；历史记录缺失返回 null |

**差异示例**（仅展示变更相关片段）

请求片段：

```json
{ "page": 0, "size": 20, "status": "ACTIVE" }
```

响应片段：

```json
{ "totalElements": 1, "content": [{ "id": "res_001", "owner_name": "alice" }] }
```

**兼容性**：旧客户端不传 `status` 行为不变；历史数据缺失 `owner_name` 时返回 `null` 而非报错。

**请求参数**

| 位置 | 字段 | 类型 | 必填 | 可为 null | 说明与约束 |
|---|---|---|---|---|---|

**请求示例**

```http
POST /api/events HTTP/1.1
Host: <服务域名>
Authorization: Bearer <token>
Content-Type: application/json

{
  "event_id": "evt_001"
}
```

**响应字段与成功示例**

| 字段 | 类型 | 必有 | 可为 null | 说明 |
|---|---|---|---|---|
| `accepted` | boolean | 是 | 否 | 事件是否受理 |

```json
{
  "accepted": true
}
```

| 场景 | HTTP 状态 | 业务码 | 调用方处理 |
|---|---|---|---|
