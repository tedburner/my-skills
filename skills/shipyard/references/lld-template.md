# LLD 模板 — 详细设计（完整模式）

适用于完整模式的详细设计；简单 CRUD 或单一模块中小改造优先使用轻量模式 [`design-template.md`](design-template.md)。

使用规则：
- 每个有效设计点用相对链接回链实际存在的 HLD 目标；编号在本文内连续分配、不回收，废弃项保留锚点及原因且不计入分母。
- 仓库 `AGENTS.md` 已固化的响应包装、命名风格、鉴权或构建约定，在公共约定中一句话引用即可；正文聚焦本需求特有的模型、流程、状态并发与契约差异。
- 新增或修改 HTTP 接口时，按复杂度选用 [`api-template.md`](api-template.md) 的三档版式（默认紧凑卡 / 增量修改 / 复杂协议完整模板）；若已同步至 YAPI/OpenAPI 等外部契约平台，可侧重差异与关键规则，不手工重复维护整套全量字段表。
- 生成时移除此使用说明、占位提示及无关示例区，重算进度。需要方法、路径对照时才保留接口总览，只列本次涉及的真实接口。
