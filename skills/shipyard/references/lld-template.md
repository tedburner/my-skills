# LLD 模板 — 详细设计

使用规则：

- 每个设计点必须回链 hld 编号；冒出无回链的新点，先回 hld 补设计。
- 编号全局连续，规则同 hld；作废点标注废弃，不删号。
- 合格标准：开发者读完一个设计点就能写代码，不需要追问字段类型、错误返回、边界行为。
- 按设计点的形态选用子模板：接口 / 表结构 / 关键流程，一个点可以同时含多段。

## A. <模块/主题域>

### [ ] 1. 聚合接口（回链 hld #4）

**接口**

- `GET /api/apps/:appId/releases?cursor=&limit=`

**请求**

| 字段 | 类型 | 必填 | 说明 |
|------|------|------|------|
| cursor | string | 否 | 分页游标，首页不传 |
| limit | int | 否 | 默认 20，上限 100 |

**响应**

```json
{ "releases": [{ "id": "r_123", "phase": "building", "createdAt": "2026-10-31T08:00:00Z" }], "nextCursor": "..." }
```

**错误码**

| code | HTTP | 含义 | 前端处理 |
|------|------|------|----------|
| APP_NOT_FOUND | 404 | 应用不存在 | 提示后返回列表 |

**幂等与状态恢复**：刷新/断线后如何回到当前状态和待确认动作（如 `?since=` 增量拉取）。
