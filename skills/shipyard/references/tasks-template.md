# 工单模板 — 任务清单及验收

每个有效任务写回链、范围、依赖和可验证的验收标准，按可独立验收的交付物划分。代码及本地验证、环境联调等待条件不同且可独立验收时分开安排；强耦合时说明组合交付及联合验收。编号稳定，拆分可用 T-3a / T-3b，原项保留历史并标明由哪些子任务替代，不再重复计数；废弃项记录原因，不计入进度。覆盖每个有效 LLD 点及关键前提验证，或说明不需任务的原因。用户授权跳过设计门禁且无 LLD 时，回链 HLD 或已有材料并记录依据，以现有有效设计和授权范围检查覆盖。

任务勾选表示其验收条件全部满足。实现完成但待验证时保持未勾选，在任务下简记实施情况，不另统计代码完成比例。拆分不得漏掉原验收条件；变更时同步范围、依赖和验收，失效的完成勾选撤销，旧验证记录注明适用范围。

以下为正文骨架，生成时移除使用说明和占位提示；按实际条目重算进度。任务按 A/B/C 模块或交付主题分组，三级标题包含勾选状态、T 编号和简短任务名，编号跨组连续；范围、依赖、验收和验证记录用加粗标签展开。接口按设计点追踪，任务仍按交付物拆分，可回链多个接口点，无需一接口一任务。
