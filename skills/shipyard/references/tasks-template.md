# 工单模板 — 任务清单及验收

使用规则：
- 每个有效任务写回链、范围、依赖和可验证的验收标准，按可独立验收的交付物划分。
- **本地交付与外部环境解耦**：本地实现任务（编码、单测、隔离容器测试、接口平台 API 写入）只绑定本地可完成验证的条件，**禁止将目标环境部署、真实测试/线上库权限、跨团队联调、DBA 建索引或人工页面预览设为本地任务的前置依赖**；这些外部依赖统一拆至后置任务，标注 `验收阶段：最终验收（外部依赖）`。
- 编号稳定，拆分可用 T-3a / T-3b；废弃项记录原因，不计入进度。用户授权跳过设计门禁且无 LLD 时，改为回链 HLD 或 `design.md`。
- **验证记录现行态优先**：同一任务多轮复验后，以最新一轮的有效范围、环境、命令和结论更新正文；已修复的中间失败仅保留一句短摘要或移除，不堆砌流水账。
- 中途引入外部补充方案或热修设计时，必须拆为新的 `T-N` 任务并回写现行设计点，**禁止在 `## 最终验收` 下方直接粘贴无编号追加段落**。
- 生成时移除此使用说明和占位提示，按实际条目重算进度；设计点较多（如 ≥ 6 个）时建议保留可选的 `设计覆盖核对` 表。
