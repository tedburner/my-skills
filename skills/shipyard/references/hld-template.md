# HLD 模板 — 概要设计（完整模式）

适用于需要“先对齐系统边界、再展开详设”的复杂项目；简单 CRUD 或单一模块中小改造请优先使用轻量模式 [`design-template.md`](design-template.md)。

使用规则：
- 设计点编号在本文内连续分配、不回收；废弃点保留编号、锚点与原因，不计入有效总数。
- 仓库 `AGENTS.md` 已固化的工程、构建、序列化和数据库约定，在“前提、约束和假设”一句话引用即可，不逐项复读。
- 本文统一维护项目阶段和下一步；方案被新版本或新目录取代时，将状态更新为 `当前阶段：已归档`、`项目状态：已归档（由 <新方案链接> 取代）`，冻结后续门禁与计数。
- 生成时移除此使用说明和占位提示，按实际条目重算进度。
