# 轻量设计模板 — 合并概要与详细设计（`design.md`）

适用于简单 CRUD、单一模块扩展、少量字段/接口变更等中小需求。将目标边界、待确认项、接口紧凑卡与关键实现约束合并在一份 `design.md` 中，同时作为状态锚点；不单独创建 `hld.md` 和 `lld.md`。

使用规则：
- 按模块或主题用 `## A. <主题>` 分组，条目用 `### [ ] N.` / `### [x] N.` 跨组连续编号并配 `<a id="design-N"></a>`。
- 仓库 `AGENTS.md` 已固化的构建、鉴权、响应包装、字段命名和读写分离等规范，在“前提与约束”一句话引用，不重复抄写。
- HTTP 接口按 [`api-template.md`](api-template.md) 选用「紧凑接口卡」或「增量修改」版式，不铺设冗余大表。
- 生成时移除此使用说明与不适用占位段，重算设计进度。
