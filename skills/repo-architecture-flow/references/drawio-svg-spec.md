# Draw.io 与 SVG 绘图、布局及防遮挡规范

本规范定义 `.drawio`（mxGraph XML）与 `.svg` 双产物的结构、图层顺序、正交连线与网格几何标准，确保在浏览器与 diagrams.net 中打开均清晰可编辑、无文字溢出、无连线压字。

---

## 一、双产物一致性与文件结构

1. **双产物同步**：每次生成或更新必须同时产出 `.svg` 与 `.drawio`，两份文件的标题、层级、模块命名、代码线索与调用方向必须完全一致。
2. **`.drawio` 原生可编辑**：
   - XML 必须包含 `<mxfile>` -> `<diagram>` -> `<mxGraphModel>` -> `<root>` 以及真实可编辑的 `mxCell` 节点和连线。
   - **严禁伪编辑**：禁止在 `.drawio` 中使用 `shape=image` 或 `data:image/...` 嵌入整张光栅/SVG 图片充当架构图。
   - 节点使用稳定、可读的语义化 `id`（如 `layer-inbound`、`domain-trade`、`adapter-rpc`、`edge-inbound-core`）。
3. **图形语义约定**：
   - 主层级外框：浅色圆角矩形（所有主层级外框保持**完全相同的 `x` 与 `width`**，左右边界严格对齐）。
   - 同层子分组（如不同入口类型、基础设施 vs 外部系统）：虚线圆角矩形。
   - 业务域/包分组容器：带独立顶部标题条的圆角大框。
   - 普通模块与能力点：圆角矩形小卡片。
   - 数据库/缓存/存储组件：可使用 `shape=cylinder3`（SVG 中用柱体或带存储标识的浅色块）。
   - 共享能力区/底部说明区/图例：独立浅色边框容器，置于核心处理下方或边角（右上/左上/右下），绝不充当主流程左右侧栏；颜色必须承载层级或链路语义并在图例中解释。

## 二、图层顺序（Z-Order）与调用链可见性（统一准则）

为彻底避免连线压盖卡片文字，同时保证主调用链清晰醒目，统一采用**「背景层走线 + 层间空白通道 + 线宽对比」**：

1. **固定渲染先后顺序（SVG DOM 顺序 & `.drawio` 的 `mxCell` 顺序一致）**：
   - **第 1 层（最底）**：主层级背景大框、虚线子分组外框、领域外框容器。
   - **第 2 层（中间）**：**所有连接线（`edge="1"` 的 `mxCell` / SVG `<path>`、`<line>`）**。严禁把所有 edge 堆在 XML 末尾，否则 diagrams.net 会把线条画在卡片和文字正上方。
   - **第 3 层（最顶）**：层级标题条、容器说明文本、业务模块卡片、子能力小卡片、图例与连线短标签。
2. **为什么背景层连线依然清晰可见**：
   - 所有跨层连线只经过**层与层之间的空白通道（Corridor）**，端点精准锚定在模块/分组外边界上，不从模块背后穿过，因此不会被卡片遮挡。
3. **主调用链 vs 辅助依赖线的视觉区分**：
   - **主调用链（实线）**：至少覆盖 `入口 -> 核心处理`、`核心处理 -> 出站适配`、`出站适配 -> 底层依赖` 三段，每段至少保留 1 条清晰主箭头或 1 条带中文短标签的总线；缩放到 75% 仍一眼看清主方向。
     - SVG：`stroke-width="2"`（范围 `1.8~2.4`），`markerWidth="11"`（`10~13`），`markerHeight="8"`（`7~10`），箭头面积不超过普通模块高度的 35%。
     - Draw.io：`endArrow=block;html=1;rounded=0;strokeWidth=2;endSize=10;fontSize=10;fontStyle=1;`。
   - **辅助链路（虚线，用于配置读取、依赖注入、初始化注册、缓存刷新、旁路训练/评测）**：
     - SVG：`stroke-width="1.4"`，`stroke-dasharray="5,4"`，`opacity="0.65"`。
     - Draw.io：`endArrow=open;html=1;rounded=0;dashed=1;strokeWidth=1.4;opacity=65;`。

## 三、正交连线与防穿插规则

1. **只允许正交线段，严禁斜线**：
   - 所有主调用链和跨层连线只能由**垂直直线、水平直线、90 度直角折线**组成：
     - SVG 垂直线：`M x1 y1 L x1 y2`
     - SVG 水平线：`M x1 y1 L x2 y1`
     - SVG 直角折线：`M x1 y1 L x1 yMid L x2 yMid L x2 y2`（禁止 `x` 与 `y` 同时变化的斜向 `L`）
   - Draw.io 连线样式统一包含：`edgeStyle=orthogonalEdgeStyle;orthogonalLoop=1;jettySize=auto;html=1;rounded=0;`。
2. **外边界锚定与显式折点**：
   - 连线只能从上一层模块/分组**底边**（`exitY=1`）出发，落到下一层模块/分组**顶边**（`entryY=0`），**禁止连到模块中心**导致线条穿过内部文字。
   - 跨列连接时，必须在 `<Array as="points"><mxPoint x="..." y="..."/></Array>` 中显式写入位于**层间空白带**的水平折点 `yMid`，不依赖 diagrams.net 自动路由猜测穿行路径。
3. **克制扇出（Fan-out）与标签避让**：
   - 一对多调用优先合并为**层间水平总线 + 短标签**（如“按路由/消息/任务分发”）或少量代表性主箭头，不画密集蛛网线。
   - 连线标签只放在线段旁的层间空白带，绝不叠在卡片标题或说明文字上。若某条线无法避免穿越卡片或压字，直接删除该线，改用总线或文字说明表达。

## 四、网格几何与文案防溢出标准

1. **禁止在含子元素的容器 `value` 中直接塞长段文字**：
   - Draw.io 容器文字默认垂直居中，极易压住内部子卡片。凡有子卡片的容器一律拆分为独立元素：
     1. 空白外框容器（或 `verticalAlign=top;spacingTop=8;` 仅放单行标题）
     2. 顶部标题条（高度 `28~34`）
     3. 独立说明文本框（高度 `18~24`）
     4. 内部子卡片网格
2. **最小安全间距（像素）**：
   - 主层级之间的纵向通道间距：`≥ 36`（有水平总线或连线标签时建议 `44~56`）
   - 容器内说明文字区与第一行子卡片纵向间距：`≥ 18`
   - 子卡片之间横向间距：`≥ 22`；纵向间距：`≥ 18`；容器左右及底部内边距：`≥ 16`
   - 容器总高度必须按 `标题高 + 说明高 + 子卡片行数 × 卡片高 + 行间距 + 上下内边距` 显式算出，禁止靠自动换行硬挤，也禁止在业务域容器内再套多层大框。
3. **字数、行数与字号底线**：
   - 模块卡片最多 **3 行**（第 1 行中文模块名，第 2 行 1–3 个代码定位短名，第 3 行职责摘要）。
   - 领域说明与图例说明最多 **2 行**。
   - 字号底线：正文/小字 `≥ 10px`，标题 `≥ 12px`。
   - 估算公式：中文单字宽约 `fontSize × 1.05`，英文/数字单字宽约 `fontSize × 0.6`，行高约 `fontSize × 1.45`。空间不足时的修复优先级固定为：**① 删减非核心文案/代码线索 → ② 加大卡片宽高与层间距 → ③ 改双行网格或总线 → ④ 微调字号（不低于 10px）**。
